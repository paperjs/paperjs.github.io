TextStory

The text of one or more linked TextItems, which it flows through in order: its content, kept in runs of characters that share a style, and the styles of its paragraphs. A text item that isn’t linked has a story of its own.

Properties

textItems

The text items that the story flows through, in order.

Read only.

    Type:

  • Array of TextItem objects
content

The text of the story, from the first of its text items to the last.

    Type:

  • String

Run
runs

The runs of the text: its ranges that each have one style throughout. Set it to plain objects with a content and style properties, which then make the whole text.

    Type:

  • Array of TextRange objects
paragraphs

The paragraphs of the text, without their line breaks. Set it to plain objects with paragraph style properties, one per paragraph.

    Type:

  • Array of TextRange objects
words

The words of the text, as the browser finds them (Intl.Segmenter), or else separated by white space.

Read only.

    Type:

  • Array of TextRange objects
letters

The letters of the text, each as readers see one (a grapheme: an emoji, or a letter with its accents), spaces and punctuation included.

Read only.

    Type:

  • Array of TextRange objects

Methods

replace(content, start, end)

Replaces the content from start to end, or of a range, with new content, which takes the style of the content it replaces, or of the character before it when it’s inserted.

    Parameters:

  • content: String — the new content
  • start: Number — the index of the first character to replace
  • end: Number — the index after the last character to replace
range(start, end)

The range of the text from start to end.

    Parameters:

  • start: Number — the index of its first character
  • end: Number — the index after its last character

    Returns:

  • TextRange
